# Suno iOS brand reference (Mobbin capture, Feb 2025)

Source: Bo's Mobbin export "Suno ios Feb 2025" (130 screens, kept outside this
repo at `../suno-screens-feb-2025/`). Digest written 2026-08-05 from 18
representative screens (0, 4, 13, 23, 30, 38, 47, 51, 55, 61, 66, 68, 74, 75,
76, 78, 83, 90, 98, 110, 117, 124). This supersedes the App Store screenshot
grounding used for the first brand pass.

## Surfaces

- Base surface is light bone (warm off-white), not dark: Discover, Library,
  Search, Create form, Profile, Song Actions, Add to Playlist, Rename, Login.
- Dark surfaces are art-driven, not chrome-driven: the full-screen player
  (vertical feed over cover art), playlist heroes (full-bleed grainy
  gradients), the paywall (dark gradient + noise), the share sheet (dark
  purple grain). Dark = immersion in content, light = utility.
- Sheets: rounded-top modals with centered Title Case headers ("Share Song",
  "Song Actions", "Add to Playlist", "Rename Song") and a circular X button
  top-right.

## Type

- Editorial display serif for: screen titles ("My Songs", "Popular
  Playlists", "Login to Suno"), profile display names ("Sam lee"), song and
  playlist titles in hero/sheet contexts ("Road Trip 24", "Romance in a
  Digital Cage"), create-form section labels ("Style", "Lyrics", "Title"),
  plan names, big numerals (credits "50").
- Neo-grotesque sans for all other UI: row titles, buttons, tags, body.
- Wide-tracked ALL-CAPS sans for profile stat chips: "1 SONG", "0 LIKES",
  "2 FANS", "9 PLAYLISTS" as icon + count + label inside bone pills.
- Centered Title Case sans for nav-bar titles ("Credits", "Profile").

## Color

- Bone base, near-black ink. No pure white/black.
- Magenta accent for interactive moments on light surfaces: toggles,
  "Restore", "Got it", "+ Follow", active "Text" tab. Sparing.
- Lime/chartreuse version chip: "v4" in black-on-lime rounded rect.
- Blue gradient pill: the persistent "Create" CTA and the circular
  create FAB next to the mini player.
- Grainy purple→orange gradient (the lava family): the generate action in
  camera create, paywall backdrop, splash. Generation = lava; navigation to
  create = blue.
- Black pill = default primary CTA ("Confirm", "Subscribe", "Save", "Use my
  phone number"). Bone/white pill = secondary ("Share").
- Toasts: black pill, white check icon + text.

## Icons and counters

- Thumbs up / thumbs down, never hearts. Play triangle for play counts,
  person glyph for creators/fans, ♪ for song counts, kebab per row.
- Counts abbreviate: 79K, 1.5K, 3.4K.
- Style-tag overflow: "romantic, ballad, melancholic, rap", "minimal,
  hip-hop, natural, +6". Titles truncate with "…".

## Voice

- Sentence case, plain, warm, contractions, occasional exclamation:
  "Profile updated!", "Your new cover image is uploaded!", "Copied Link".
- Generation status is playful and musical: "Strumming up something special".
- Coach marks teach in one sentence + magenta "Got it":
  "Suno always gives you two songs so you can pick your favorite".
  Gesture glyph + dimmed backdrop; "Tap for details" caption idiom.
- Empty states: bold "Nothing here yet" + quiet "Try adding some songs from
  your library".
- Destructive confirms are human: "Delete playlist?" / "You can't get it
  back once you press Delete".
- Actions are short Title Case verb phrases: "Rename Playlist", "Make
  Public", "Make Random Lyrics", "New Playlist"; "Remaster" carries a v4
  chip.
- Discover section headers: "New Songs", "Top Categories", "Fresh from v4",
  "Global Trending", each with a "More >" link. Search placeholder: "Search
  songs, users or playlists".
- Profile: "Creators to follow", "Popular on Suno", fans not followers.
- Brand marquee (splash): "DIY MUSIC / WE'RE ALL CREATORS / BRING BACK THE
  FUN".

## Patterns

- Segmented pill controls, active = black pill with white text
  (Discover/Library; All/Songs/Scenes; Songs/Users/Playlists).
- Mini player bar (dark, rounded) + blue circular create FAB above the home
  indicator.
- Player is a vertical swipe feed: full-bleed art, title + v4 chip + creator
  top-left, right-side action rail (thumb up with count, thumb down, share,
  more), restart + pause + scrub bottom, swipe-up hint to next song.
- Create form: serif section labels, bone input cards, suggestion chips
  ("Surprise me" with dice icon, "mantra", "hardstyle"), char counters
  ("0 / 3000", "25 / 80"), Custom toggle, Instrumental toggle, bottom mode
  tabs Text / Camera / Audio.
- Coach-mark overlay is the sanctioned in-product guidance surface.
